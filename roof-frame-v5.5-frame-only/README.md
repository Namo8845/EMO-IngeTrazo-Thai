## วิธีติดตั้ง

1. ดาวน์โหลด ZIP แล้ว **แตกไฟล์ทั้งหมด (Extract All)**
2. ปิด IngeTrazo แล้วรัน `INSTALL_WINDOWS.cmd` จากโฟลเดอร์ที่แตกไฟล์
3. เปิด IngeTrazo แล้วเลือก `Extensions > EMO Roof Frame v5.5 FRAME ONLY BETA…`

ตัวติดตั้งสำรองปลั๊กอินรุ่นเดิมก่อนคัดลอกไฟล์ใหม่

## สถานะ / ข้อจำกัด

**BETA — ไม่ใช่แบบโครงสร้างที่ผ่านการรับรอง** รูปทรงหน้าตัด จุดต่อ และขนาดเป็นตัวอย่างสำหรับโมเดล ต้องตรวจและคำนวณโดยวิศวกรก่อนผลิตหรือก่อสร้าง ใช้กับผังสี่เหลี่ยมแนวแกน X/Y ได้ก่อน และยังไม่ได้ยืนยันการทำงานครบทุกเวอร์ชันของ IngeTrazo บน Windows
