# EMO IngeTrazo Thai Extension (Preview)
ส่วนเสริมภาษาไทยสำหรับ IngeTrazo บน Windows — โครงการชุมชน ไม่ใช่ส่วนเสริมทางการ

## ติดตั้ง
1. ติดตั้ง IngeTrazo จาก https://github.com/ingelibre/ingetrazo/releases
2. ดาวน์โหลดซอร์สโค้ดของ repo นี้ด้วย Code → Download ZIP และแตกไฟล์
3. ดับเบิลคลิก `INSTALL_THAI.cmd` แล้วเปิด IngeTrazo ใหม่
4. เข้า **View → Language → ไทย (Thai)** และเปิดโปรแกรมใหม่

ตัวติดตั้งจะคัดลอกปลั๊กอินไปที่ `%APPDATA%\ingetrazo\plugins\emo_thai_ui.py`
และไม่เปลี่ยนไฟล์ .exe ของโปรแกรมหลัก

## สถานะ
**Preview — ยังไม่ครบ 100%** คำแปลที่มีรองรับเมนูหลัก แท็บ และหมวดวัสดุบางส่วน
รองรับการสลับกลับไป English โดยไม่แก้ข้อความต้นฉบับของภาษาอังกฤษ
ชื่อไฟล์และชื่อวัตถุของผู้ใช้ไม่ควรถูกแปล
